# 🚀 Featured Work

## 🥇 SERVORA

### `Hyperlocal Home-Services Marketplace`

> **My flagship independent project --- conceptualized, designed and
> developed from scratch.**

SERVORA is a full-stack hyperlocal marketplace connecting customers with
verified local professionals such as electricians, plumbers, cleaners,
carpenters and more.

The platform covers the complete service journey --- **discovery →
booking → assignment → communication → payment → completion → review**.

### ✨ Core Features

**Customer** - Email/password, mobile OTP & Google Sign-In - Location
detection & address search - Service booking and booking history -
Razorpay payments and refunds - Coupons and referral wallet - Real-time
professional chat - Professional details after assignment - Ratings and
reviews

**Professional** - KYC registration with document uploads - Admin
approval workflow - First-come-first-served job requests - Job
acceptance/rejection - Google Maps navigation - Availability toggle -
Earnings dashboard & withdrawal requests - Reviews management

**Admin** - Professional KYC approval/rejection - Service and
service-area management - Configurable commission - Coupon management -
Refund management - Withdrawal processing - Revenue and platform
analytics

### 🧩 Architecture & Technologies

``` text
Frontend      → HTML • CSS • Vanilla JavaScript • Leaflet.js • GSAP
Backend       → Node.js • Express.js
Database      → MongoDB Atlas
Auth          → JWT • bcrypt • Google OAuth • Mobile OTP
Realtime      → Socket.IO
Payments      → Razorpay
Security      → Helmet • express-rate-limit
Deployment    → Render • GitHub • MongoDB Atlas
```

### 🔗 Project

**Live Demo:** `https://servora-project.onrender.com`\
**Source:** Private Repository

> SERVORA is more than a UI project --- it is my attempt to design and
> implement a complete real-world marketplace workflow.
